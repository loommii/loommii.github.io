# Go每日一题_063


下面这段代码输出什么？

```go
func main() {  
    i := 65
    fmt.Println(string(i))
}
```

A. A
B. 65
C. compilation error

{{< details summary="🔑 答案解析：" >}}

 A
UTF-8 编码中，十进制数字 65 对应的符号是 A。

{{< /details >}}
