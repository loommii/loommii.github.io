定义一个包内全局字符串变量，下面语法正确的是（多选）：

  • A. var str string
  • B. str := ""
  • C. str = ""
  • D. var str = ""
🔑 答案解析：

A D

只有 用var来定义才能在全局定义

B 只支持局部变量声明 C 赋值,不是定义
