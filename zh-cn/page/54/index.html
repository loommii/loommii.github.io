loommii 发布于 2024-12-06 收录于 Go每日一题  Go语言基础

下面这段代码能否通过编译，如果可以，输出什么？

1
2
3
4
5
6

func main() {
    s1 := []int{1, 2, 3}
    s2 := []int{4, 5}
    s1 = append(s1, s2)
    fmt.Println(s1)
}
🔑 答案解析：

答: 无法通过编译。 append() 的第二个参数不能直接使用 slice，需使用 … 操作符，将一个切片追加到另一个切片上：append(s1,s2…)。或者直接跟上元素，形如：append(s1,1,2,3)。
