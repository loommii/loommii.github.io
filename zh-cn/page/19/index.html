import (
       "fmt"
)

func hello(i int) {
       fmt.Println(i)
}
func main() {
       i := 5
       defer hello(i)
       i = i + 10
}
🔑 答案解析：

5 在线运行 Go传递只有值传递
运行到defer hello(i)的时候就已经确定i的值了
