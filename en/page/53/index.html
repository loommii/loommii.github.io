Go Daily Question 020

loommii published on 2024-12-06 included in GoDailyQuestion  GoLanguageBasics

Will the following code compile? If so, what will be the output?

1
2
3
4
5
6

func main() {
    s1 := []int{1, 2, 3}
    s2 := []int{4, 5}
    s1 = append(s1, s2)
    fmt.Println(s1)
}
🔑 Answer Analysis:

Answer: Cannot compile. The second argument of append() cannot directly use a slice; it requires the ... operator to append one slice to another: append(s1, s2...). Alternatively, elements can be appended directly, such as: append(s1, 1, 2, 3).
