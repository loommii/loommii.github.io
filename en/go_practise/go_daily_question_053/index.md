# Go Daily Question 053


To define a package-level global string variable, which of the following syntax is correct (multiple choice):

A. var str string
B. str := ""
C. str = ""
D. var str = ""

{{< details summary="🔑 Answer Analysis:" >}}

A, D
The key is "package-level global".
B: `:=` can only be used inside functions.
C: This is an assignment, not a declaration.
