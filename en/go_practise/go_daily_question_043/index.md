# Go Daily Question 043


What is the output of the following code?

```go
package main

import (
    "encoding/json"
    "fmt"
)

type AutoGenerated struct {
    Age   int    `json:"age"`
    Name  string `json:"name"`
    Child []int  `json:"child"`
}

func main() {
    jsonStr1 := `{"age": 14,"name": "potter", "child":[1,2,3]}`
    a := AutoGenerated{}
    json.Unmarshal([]byte(jsonStr1), &a)
    aa := a.Child
    fmt.Println(aa)
    jsonStr2 := `{"age": 12,"name": "potter", "child":[3,4,5,7,8,9]}`
    json.Unmarshal([]byte(jsonStr2), &a)
    fmt.Println(aa)
}
```

- A：[1 2 3] [1 2 3]
- B：[1 2 3] [3 4 5]
- C：[1 2 3] [3 4 5 6 7 8 9]
- D：[1 2 3] [3 4 5 0 0 0]

{{< details summary="🔑 Answer Analysis:" >}}

Answer: B
Analysis:
When JSON deserializes, slices are handled by setting the slice's `len` to 0 and then appending data.
Because `aa := a.Child`, both `aa` and `a.Child` slices point to the same array. When appending to 6, since `a.Child` had not yet expanded, modifying the underlying array was equivalent to modifying `aa`'s data. However, when appending to 7, the `a.Child` slice expanded and pointed to a new array.
Therefore, the data of `aa` is `[3 4 5]`.
