# Go Daily Question 145


To define a package-level global string variable, which of the following syntax is correct (multiple choice):

- A. var str string
- B. str := ""
- C. str = ""
- D. var str = ""

{{< details summary="🔑 Answer Analysis:" >}}

A, D

Only `var` can be used for global definitions.

B: Only supports local variable declaration.
C: Assignment, not definition.
