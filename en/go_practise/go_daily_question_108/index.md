# Go Daily Question 108


Regarding type conversion, which of the following options is correct?

```go
A.
type MyInt int
var i int = 1
var j MyInt = i

B.
type MyInt int
var i int = 1
var j MyInt = (MyInt)i

C.
type MyInt int
var i int = 1
var j MyInt = MyInt(i)

D.
type MyInt int
var i int = 1
var j MyInt = i.(MyInt)

```

{{< details summary="🔑 Answer Analysis:" >}}

C

{{< /details >}}
