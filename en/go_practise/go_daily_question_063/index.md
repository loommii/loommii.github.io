# Go Daily Question 063


What is the output of the following code?

```go
func main() {  
    i := 65
    fmt.Println(string(i))
}
```

A. A
B. 65
C. compilation error

{{< details summary="🔑 Answer Analysis:" >}}

A
In UTF-8 encoding, the decimal number 65 corresponds to the symbol 'A'.
