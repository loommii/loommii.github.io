# Go Daily Question 120


In the following code, `x` is declared, `y` is not declared. Determine whether each statement is correct.

```go
A: x, _ := f()
B: x, _ = f()
C: x, y := f()
D: x, y = f()

```

{{< details summary="🔑 Answer Analysis:" >}}

A is wrong, B is correct, C is correct, D is wrong.

{{< /details >}}
